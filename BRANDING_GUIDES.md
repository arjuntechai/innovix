# Branding Guides for Innovix

This document contains the core design system extracted from the web application to ensure all external communications, such as HTML emails, stay on-brand.

## 🎨 Color Palette

### Base Colors
- **Background Color:** `#0a0a0a` (Dark mode default)
- **Text Color (Primary):** `#e8e8e8` (Off-white for high contrast on dark backgrounds)

### Accent Colors
- **Accent Default:** `#9CAF88` (Use for primary buttons, links, and highlights)
- **Accent Hover:** `#ADBE9C` (Use for button/link hover states if supported)
- **Accent Active:** `#8FA37E` (Use for active/pressed states if supported)

## 🔤 Typography

### Primary Font (Body Text)
- **Font Family:** `Inter`, `system-ui`, `sans-serif`
- Use this for all standard paragraph text, small links, and secondary information.

### Display Font (Headings)
- **Font Family:** `"Instrument Serif"`, `serif`
- Use this for primary headers (H1, H2), hero section text, or anywhere you need a stylized typographic impact.

## 📐 Design System & Structure

1. **Dark Theme Bias:** The brand heavily leans into a dark theme. Ensure your designs render the `#0a0a0a` background effectively.
2. **Clean & Minimalist:** Stick to the core colors. Use `#e8e8e8` for standard text and `#9CAF88` strategically to draw attention to call-to-actions (CTAs).
3. **Texture (Web App Specific):** The web app uses a very subtle noise texture. While complex to replicate in standard HTML emails, you can achieve a similar premium feel by keeping the layout uncluttered and focusing on high-quality typography.
